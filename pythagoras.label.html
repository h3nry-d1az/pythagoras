class pythagoras.label.Label(x: float, y: float, tag: str, padding: float = 0.05, zord: int = 0)[source]¶

Bases: PObject

A text label rendered from \({\rm \LaTeX}\).

Variables:

  • x (float) – \(x\)-coordinate in Cartesian space.

  • y (float) – \(y\)-coordinate in Cartesian space.

  • tag (str) – \({\rm \LaTeX}\) string to render inside the label.

  • padding (float) – Spacing around the label (default 0.05).

  • zord – Drawing order; higher values are drawn later.

classmethod anchored(point: tuple[float, float], direction: AnchoringDirection, tag: str, offset: float = 0.33, padding: float = 0.05, zord: int = 0) → Self[source]¶

Creates a label anchored to a given point in \(\mathbf R^2\).

Parameters:

  • point – Point to which the label is anchored.

  • direction – Anchoring direction (north, west…). See AnchoringDirection for further information.

  • tag – \({\rm \LaTeX}\) string to render inside the label.

  • offset – Distance between the point to which the label is anchored and the label itself (default 0.33).

  • padding – Spacing around the label (default 0.05).

  • zord – Rendering priority.
